Persistent VM management for macOS using vfkit + EFI boot.

Subcommands mirror the Linux libvirt/ module structure: run, list, ssh, stop, start, rm, rm-all, inspect

Modules§

vm inspect — Show detailed VM information.

vm list — List all persistent VMs.
rm
vm rm — Remove a persistent VM and its metadata.
rm_all
vm rm-all — Remove all persistent VMs.
run
vm run — Start a persistent VM from a disk image using vfkit + EFI boot.
ssh
vm ssh — SSH into a running persistent VM.
start
vm start — Restart a stopped persistent VM.
stop
vm stop — Stop a running persistent VM.
